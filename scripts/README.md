# Mappa degli script · Script map

🇮🇹 Lo **spine numerato** (`00→99`) è piatto in `scripts/` e codifica la **fase** della pipeline (dati→train→backtest→live), **non** la linea di ricerca. La distinzione vol-volatilità vs direzionale-rendimenti **non** è una biforcazione di codice: è lo stesso motore (`quantsys/`) con un interruttore di config (`features.target_type`: `log_rv` per la vol, `ret` per i rendimenti). Gli script **non numerati** specifici di linea vivono in sottocartelle (`vol/`, `research/`, `vps/`, `archive/`) e usano `Path(__file__).resolve().parents[2]` → vanno lanciati dalla **root di progetto**.

**EN** The **numbered spine** (`00→99`) is flat in `scripts/` and encodes the pipeline **phase** (data→train→backtest→live), **not** the research line. The vol-volatility vs directional-returns split is **not** a code fork: it is the same engine (`quantsys/`) with a config switch (`features.target_type`: `log_rv` for vol, `ret` for returns). Line-specific **non-numbered** scripts live in subfolders (`vol/`, `research/`, `vps/`, `archive/`) and use `Path(__file__).resolve().parents[2]` → run them from the **project root**.
