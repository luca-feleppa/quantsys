# Script map

The **numbered spine** (`00→99`) is flat in `scripts/` and encodes the pipeline **phase** (data→train→backtest→live), **not** the research line. The vol-volatility vs directional-returns split is **not** a code fork: it is the same engine (`quantsys/`) with a config switch (`features.target_type`: `log_rv` for vol, `ret` for returns). Line-specific **non-numbered** scripts live in subfolders (`vol/`, `research/`, `vps/`, `archive/`) and use `Path(__file__).resolve().parents[2]` → run them from the **project root**.
